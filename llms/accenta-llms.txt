# Accenta

> Accenta is a French energy and carbon performance company for real estate portfolios, founded in
> 2016 in Boulogne-Billancourt. It pairs AI-driven building control with low-carbon heat and cold
> production based on shallow geothermal energy and inter-seasonal geostorage, and delivers the whole
> thing as audit, design, build, operate, financing and performance-contract services. Its software
> platform is effiPilot, acquired in 2020. Accenta says it manages around 10 million m² of real
> estate for owners including Airbus, Prologis, Icade, Redevco and Decathlon.

## What an agent can and cannot do here

Accenta has a real HTTP API, but it is a customer platform API, not a developer product:

- The API is RPC-over-HTTP: `https://<tenant>.accenta.ai/api/method/<methodName>`, JSON in and out.
- Each customer estate is its own host on the wildcard `*.accenta.ai` origin. Note that the wildcard
  answers EVERY label with the login application, so a 200 on `something.accenta.ai` proves nothing
  about that subdomain existing as a product.
- Authentication is a server-side session cookie established through the platform login. No API key,
  no OAuth 2.0, no OIDC discovery. No machine-to-machine credential is documented publicly.
- The API reference exists and is Accenta's own — "documentation API effiPilot" at
  `/api/doc` on the tenant host — but it is served only to an authenticated session. An anonymous
  request returns `{"message":"Route not found"}`.
- Exactly one method is reachable anonymously: `GET /api/method/brandConf`, which returns tenant
  branding, the Accenta SAS legal entity block and the current EULA/RGPD document versions.
- There is NO OpenAPI, Swagger, GraphQL, AsyncAPI, MCP server or A2A agent card on any Accenta host,
  and no `/.well-known/` document of any kind. Do not go looking for one; it has been checked.

## APIs

- [effiPilot Platform API](https://app.accenta.ai/login/?redirectTo=api%2Fdoc): RPC-style JSON API
  behind the effiPilot building-energy platform. Base `https://app.accenta.ai/api/`. Reference gated
  behind the customer login.
